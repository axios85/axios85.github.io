Redundancia y Alta Disponibilidad

La resiliencia en infraestructura de TI se construye mitigando puntos únicos de fallo. Este laboratorio abarca desde la agregación de enlaces a nivel de capa de enlace de datos (NIC Teaming/Bonding) hasta la distribución de carga de aplicaciones.

❖

1. NIC Teaming en Windows

Configuración nativa de agregación de adaptadores de red (LBFO) en entornos Windows Server.

Modo Switch Independent

Permite conectar los adaptadores a switches físicos diferentes. No requiere configuración previa en la infraestructura de conmutación.

🧪 Lab Config

Modo LACP

Agregación dinámica dependiente del switch. Utiliza el protocolo Link Aggregation Control Protocol para negociar los enlaces de forma automática.

🧪 Lab Config
🐧

2. NIC Teaming en Linux

Implementación de Network Bonding en Linux para conseguir tolerancia a fallos y agregación de ancho de banda.

Modo Active-Backup (Mode 1)

Solo una interfaz del conjunto está activa. Si el adaptador principal falla, una interfaz secundaria toma el control inmediatamente de forma transparente.

🧪 Lab Config

Modo Round Robin (Mode 0)

Transmite los paquetes de forma secuencial desde el primer esclavo disponible hasta el último, proporcionando balanceo de carga estático.

🧪 Lab Config

Modo LACP (802.3ad / Mode 4)

Crea grupos de agregación dinámica que comparten la misma velocidad y configuraciones de dúplex mediante la norma IEEE 802.3ad.

🧪 Lab Config
⎋

3. Server Load Balancing (SLB)

Distribución de tráfico de red a nivel de aplicación para garantizar el escalado y alta disponibilidad de servicios.

HAProxy Load Balancing

Configuración de HAProxy como proxy inverso y balanceador de carga de alto rendimiento para protocolos TCP y HTTP.
